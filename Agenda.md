# Intro to Vibe Coding — 1-Hour Agenda

**Session goal:** Understand AI coding assistants and build a Hello World app with Copilot CLI.

**Framing:** AI is an *assistant*, not an *oracle*.

## 0–5 min — Setup

- Introduce the session goal: understand AI coding assistants and build a Hello World app with Copilot CLI.
- Frame AI as an assistant, not an oracle.

---

## 5–25 min — Intro Slide Deck: AI for Code

- **What AI is:** a probabilistic prediction engine.
- **Why it feels intelligent:** pattern matching + context.
- **Why it can build code:** trained on examples, docs, syntax, and patterns.
- **Limits:** hallucinations, outdated assumptions, security risks.
- **Vibe coding:** conversationally steering code creation.
- **Best practice:** the human owns architecture, validation, and final decisions.
- **The specification is the "source of truth."**
- Compare good prompt vs. bad prompt examples.
- **Workflow:** spec → generate → inspect → run → test → refine.

> **Transition:** "Now let's use Copilot CLI."

---

## 25–30 min — Break / Environment Check

Confirm each attendee has:

- [ ] A GitHub account with Copilot access
- [ ] A terminal ready to go
- [ ] VS Code (optional)
- [ ] Node/npm or GitHub CLI installed, depending on install method

---

## 30–55 min — Crash Course Lab: Copilot CLI Hello World

1. Install Copilot CLI.
2. Authenticate.
3. Trust the working directory.
4. Create a simple app.
5. Run it.
6. Ask Copilot to explain and improve it.
7. Add a small test or README.

> **Note:** GitHub's current docs say Copilot CLI is available with all Copilot plans, but organizations may need to enable the policy. It also supports trusted directories, tool access, and file/URL permissions.

---

## 55–60 min — Wrap-up

- What worked?
- What still needs human review?
- Give attendees a repeatable checklist.
