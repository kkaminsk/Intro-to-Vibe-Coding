# Lab 1 · Step 8 — Add a Small Test or README

## 🎯 Goal

Finish the project like a real developer would: document it or add a test so others (and future you) understand and trust it.

## Option A — Add a README

Type this prompt into Copilot:

```text
Create a README.md for this project. Include: a one-line description,
how to install/run it, an example of the output, and a short "What I
learned" section. Keep it beginner friendly.
```

## Option B — Add a small test

Type this prompt into Copilot instead (or as well):

```text
Add a small automated test for the greeting logic in app.js. Refactor
the greeting into a testable function if needed, then write a simple
test file that checks it returns the right greeting for morning,
afternoon, and evening. Show me how to run the test.
```

## 👀 What to expect

- Copilot creates `README.md` and/or a test file and asks to save them.
- Approve the changes.
- If you added a test, ask Copilot to run it and show the results.

## Run the test (if you added one)

```text
Run the test and show me the output. If it fails, fix it and run
it again.
```

## ✅ What success looks like

- Your folder now has a `README.md` and/or a passing test.
- You have a small, documented, working project built entirely by prompting Copilot CLI.

## 🎉 Congratulations — lab complete!

You installed Copilot CLI, authenticated, trusted a folder, and used prompts to create, run, improve, and document a real app.
